# Developing TrackMyRoyalties

React 19 + [Astryx](https://github.com/facebook/astryx) (Meta's design system, pinned at 0.7.16), built with Vite. The data, import, and demo logic is the original app's plain-JavaScript code in `src/core/classic/`, kept unchanged so existing users' saved data loads exactly as before.

## Run it

Requires Node 22+ (`nvm use 24`).

```bash
npm ci
npm run dev            # live-reloading dev server
npm run build          # production build in dist/
npx vite preview       # serve dist/
```

Data is stored per address (origin): `npm run dev`, `vite preview`, and the desktop app (port 8788) each have their own saved data. Use the same address to keep the same data.

## Deploying

Vercel builds on push to `master` using `vercel.json` (`npm ci`, `npm run build`, serve `dist/`). The desktop launcher (`Launch TrackMyRoyalties.command`, `desktop/app.py`) serves the same `dist/` build.

`public/sw.js` retires the service worker the original app installed for offline use: returning visitors get their old caches deleted and the worker unregistered. The current app doesn't use a service worker.

## Checks

```bash
npm run lint             # ESLint + React Compiler rules (eslint-plugin-react-hooks)
npm run check:compiler   # fails if React Compiler skips any function
npm run build
```

## Versions

- **Astryx** is pinned to exactly `0.7.16` (it's a beta). Upgrade on purpose, then run the checks.
- **React 19** with **React Compiler 1.0** (`babel-plugin-react-compiler`), wired through Vite in `vite.config.js`. `@babel/core` stays on 7: the compiler's AST handling doesn't support Babel 8 yet.
- **SheetJS 0.20.3** from SheetJS's own CDN (npm only has 0.18.5, which has known security issues). Loaded only when an Excel file is opened.

## Code layout

```
src/
  main.jsx            loads saved data, then renders
  App.jsx             app shell, navigation, confirmations, toasts, demo-data actions
  appContext.js       UI services shared with pages (toast, confirm, navigate, filters…)
  options.js          Selector option lists, small text helpers
  core/               the data model and parsers, re-exported by name
    classic/            the original app's plain scripts (data.js, import.js, brand.js,
                        platform-icons.js), unchanged; they attach to `window`
    ledger.js           platforms, aggregation, formatting, persistence
    importers.js        report parsers, export guides, lazy Excel support
    files.js            reading report files, downloads
    platformLogos.js    store logos
  store/ledgerStore.js  the data: read with useLedger(), changed only through its named actions
  assets/platforms/   store logos
  themes/writers-desk/  the Writer's Desk theme as the app uses it (generated; see Themes)
  components/         page frame, panels, KPI tiles, filters, charts, store logos, vault controls
  dialogs/            add/edit expense and title, merge titles, chart annotation
  pages/              one file per page; import/ holds the Import page's parts
```

## How state works

- The saved data lives in IndexedDB, an external store. Components read it with `useLedger()` (built on `useSyncExternalStore`), not by copying it into React state.
- It's loaded once in `main.jsx`, before the first render, so there's no loading state.
- It changes only through the named actions in `store/ledgerStore.js` (`saveExpense`, `mergeBooks`, `importRoyaltyRows`…). They update immutably, which React Compiler requires: an action gets a draft with fresh copies of each list, and replaces any item it changes instead of editing it.
- There's no `useEffect`, `useMemo`, `useCallback`, or `useRef` in `src/`. The compiler handles memoization, and nothing needs an effect: data loads before render, and save errors and storage usage come from the store.

## Themes

Users pick a theme in Settings; **Writer's Desk** is the default (`npx astryx theme use <slug>` changes the default, `src/astryx-themes.js` is generated by `npx astryx theme add`). Neutral, Y2K, and Gothic are Astryx packages.

Writer's Desk extends Y2K and was made with Astryx's (experimental) theme editor:

- `themes/writers-desk/` is the editor's source: `writers-desk.settings.json` holds every setting; `writers-desk.theme.ts` is yours to edit by hand.
- `src/themes/writers-desk/` is the generated copy the app imports. Commit both.
- Change it with the editor, which checks each change against what Astryx components read and rebuilds both folders, e.g. `npx astryx experimental theme editor set writers-desk accent "#2b4c7e"`. Add `show writers-desk --png` to render previews (gitignored).
- Headings use Literata (`@fontsource/literata`, bundled, so it works offline); `src/styles.css` loads its 600 weight.

`src/styles.css` also widens the expanded sidebar to 290px (Astryx has no width setting), so the app name fits in the wider-font themes.
